# My NeetCode practice

I keep my Python coding exercises here so I can revisit earlier attempts and compare how I approached a problem.

The repository includes duplicate detection, anagram checks, sorting examples and unpacking exercises. Some problems have multiple submissions; I keep those attempts rather than presenting them as one finished solution.

## Organization

- `Data Structures & Algorithms/`: problem submissions.
- `Python Coding Interviews/`: Python language and sorting practice.

These are individual exercises rather than an application or a shared test suite. Some submissions rely on the exercise platform’s harness and imports. When I revisit one, I check its expected input/output and run it in the appropriate harness.

I’m using this repository to get more comfortable explaining the tradeoffs in my solutions, not just reaching an accepted answer.
