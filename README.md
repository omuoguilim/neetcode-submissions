# NeetCode Practice

My Python submissions for coding-interview practice, synced from NeetCode. This is a collection of individual exercises rather than a standalone application.

| Folder | Exercises |
| --- | --- |
| [Data Structures & Algorithms](Data%20Structures%20%26%20Algorithms/) | Duplicate detection and anagram checking |

Multiple `submission-N.py` files preserve separate attempts. Their presence alone does not establish that every attempt passed.

## Reading and running a solution

Open a problem folder and select a submission. These files are written for the platform's exercise harness, so running a file directly may produce no output. Some use names supplied by the platform, such as `List`; add `from typing import List` when adapting those files for a local Python 3 harness.

Use the matching problem's inputs and expected outputs to check behavior. There is no repository-wide test runner or package installation step.

## Synchronization

New submissions may arrive through NeetCode's GitHub integration. Manage sync preferences on [NeetCode](https://neetcode.io/profile/github).

The earlier integration-generated README listed all platform-supported languages. The committed solutions in this repository are currently Python.
